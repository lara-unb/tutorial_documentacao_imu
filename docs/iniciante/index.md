# Nível iniciante

Coleta de dados de uma IMU com o software do fabricante, sem programação.

## Antes de começar

- Computador com Windows ou macOS
- Maleta do kit com pelo menos um dongle e uma IMU
- Cabo USB com conector Mini USB
